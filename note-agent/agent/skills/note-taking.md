# Note-taking workflow

## 1. Understand the user's intent

Determine what the user wants:
- **Capture**: Save a new idea, thought, or information
- **Organize**: Categorize, tag, or restructure existing notes
- **Find**: Search across platforms for specific content
- **Connect**: Link related notes or ideas together
- **Review**: Summarize or revisit older notes

## 2. Choose the right platform

- **Convex**: Default for general note capture. Fast, always available.
- **Notion**: For structured databases, collaborative docs, or wikis.
- **Obsidian**: For local markdown vault, personal knowledge management.
- **Craft**: For polished, design-forward notes (macOS only).
- **ClickUp**: For task-linked notes and project documentation.

## 3. Cross-platform search

When searching across platforms:
1. Search the user's primary platform (ask if unsure)
2. If not found, search other configured platforms
3. Present results consolidated with platform labels

## 4. Organization rules

- Use consistent tags: `project/<name>`, `topic/<area>`, `status/active|archive|reference`
- Suggestions welcome: "I notice you have 5 notes about X — want me to tag them?"
- Date-stamp meeting notes: `YYYY-MM-DD-meeting-topic`
