# Summarization guidelines

## When to use

- User asks "summarize this note/article/conversation"
- User asks "what are the key points from..."
- User wants a TL;DR of a long document
- User wants weekly/monthly note review

## Output format

### One-paragraph summary (default)
A single paragraph covering the essential points. Max 3-4 sentences.

### Bullet-point summary (for complex content)
- Key finding/point 1
- Key finding/point 2
- Key finding/point 3
- **Action item**: what to do next (if applicable)

### Structured summary (for research/decisions)
- **Topic**: what this is about
- **Key points**: 3-5 bullet points
- **Conclusions**: what was decided or found
- **Next steps**: any follow-up actions
- **Tags**: suggested tags for this content

## For note collections

When summarizing multiple notes:
1. Group by topic or theme
2. Identify common patterns
3. Highlight unique or outlier points
4. Suggest organizational improvements
