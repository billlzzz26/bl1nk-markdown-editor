# Research protocol

## When to use

Trigger this skill when:
- The user asks for current information ("what's new in...")
- The user asks for factual information you're not certain about
- The user wants to compare options, tools, or services
- The user is making a decision and needs data points
- Cross-referencing information across note platforms

## Procedure

### 1. Search existing notes first

Before going external, search the user's note databases:
- Convex: `search_notes` for relevant existing notes
- Other platforms as available

### 2. External research (when needed)

Use available web research tools or connections to gather current information.

### 3. Synthesize

Combine findings from notes and external sources into a coherent answer:
- What the user already knows (from their notes)
- What's new (from external research)
- Actionable recommendations

### 4. Offer to save

If the research produces useful information, offer to save it as a note:
- "Should I save this as a reference note?"
- Suggest appropriate tags
